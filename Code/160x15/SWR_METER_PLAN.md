# План доработки индикации КСВ — версия 160x15

Документ фиксирует текущее состояние измерительной части и согласованный план. **Это только план: код измерителя и дисплея пока не меняется.**

## 1. Аппаратная схема

В измерителе используется тандем-матч. На его выходах установлены нагрузки 50 Ом и выпрямители с удвоением напряжения на диодах 1N4148. Соотношение витков в тандем-матче — 1:10.

Задача индикации — не лабораторное измерение, а понятная ориентировочная цифра КСВ: например, 1.50 или 2.70. Высокая точность не является целью.

## 2. Что уже делает программа

Пины заданы так:

- `fwdpin = 15` — прямая волна;
- `revpin = 16` — отражённая волна.

Текущие переменные `fwdpower` и `revpower` имеют тип `uint16_t`.

В `powermeter()` для каждого входа сначала выполняется одно холостое чтение АЦП, затем второе чтение участвует в обновлении сглаженного значения:

```cpp
analogRead(fwdpin);
fwdpower = (12 * fwdpower + 4 * (analogRead(fwdpin) + 1)) >> 4;

analogRead(revpin);
revpower = (12 * revpower + 4 * (analogRead(revpin) + 1)) >> 4;
```

Эту часть пока не трогаем: не меняем количество чтений, коэффициенты, фильтр или типы переменных. Пользователь не хочет сейчас восстанавливать историю настройки сглаживания, поэтому существующее поведение сохраняется полностью.

На главном экране КСВ выводится только в ветке передачи `txen`. Сейчас используется формула:

```cpp
int swr1 = (long)(fwdpower + revpower) * 100 / (fwdpower - revpower);
```

Текущий вывод уже использует две цифры после десятичной точки: например, `1.33`. Отдельного ограничения максимального значения нет.

## 3. Найденная проблема

Проверка сейчас написана как:

```cpp
if ((fwdpower - revpower) > 0)
```

Обе переменные — беззнаковые `uint16_t`. Когда отражённая волна больше прямой, вычитание не становится отрицательным: оно переходит через границу беззнакового типа. Поэтому проверка не защищает расчёт, и на дисплей может попасть бессмысленное значение.

Кроме того, результат сейчас записывается в `int`, который на целевой AVR-платформе имеет 16 бит. Для расчётной части лучше использовать 32-битную целочисленную арифметику.

## 4. Предлагаемое поведение после доработки

1. **Не менять измерение FWD/REV.** Оставить текущие чтения АЦП и текущее сглаживание без изменений.
2. **Не вводить новый порог малого сигнала.** Сохранить существующее условие отображения во время передачи и нынешнее поведение при отсутствии сигнала. Дополнительную фильтрацию показаний не добавлять.
3. **Защитить деление сравнением до вычитания.** Расчёт выполнять только при `FWD > REV`. При равных или обратных показаниях деление не выполнять; для ненулевого сигнала предложено показывать `---`. При нулевых FWD и REV оставить нынешнее отсутствие числового показания.
4. **Сохранить формулу КСВ:**

   `КСВ = (FWD + REV) / (FWD - REV)`.

   Измерительные значения остаются теми же; исправляется только безопасное вычисление.
5. **Считать целыми числами в сотых долях**, без `float`:

   `КСВ × 100 = ((uint32_t)FWD + REV) × 100 / (FWD - REV)`.

   Перед вычитанием обязательно проверяется `FWD > REV`; операнды суммы переводятся в 32-битный тип до сложения.
6. **Ограничить верхнее отображаемое значение 9.99.** Если расчёт дал больше 999 сотых, для вывода использовать 999. То есть максимум на экране — `9.99`.
7. **Оставить два знака после точки.** Примеры: `1.00`, `1.33`, `2.70`, `9.99`.
8. **Не менять шкалы прямой и отражённой волны**, а также остальные элементы главного экрана.

## 5. Почему без усложнения измерительной части

Удвоители на 1N4148 имеют нелинейность, особенно на малых уровнях сигнала. Поэтому показание будет ориентировочным и может зависеть от мощности и частоты. Для поставленной задачи достаточно устойчиво отображать порядок КСВ — например, отличать 1.5 от 2.7. Калибровку, новые пороги и дополнительные фильтры в эту доработку не включаем.

## 6. Граница работ

На следующем этапе предполагается изменить только расчёт и вывод числа КСВ в `mainscreen()`. Функцию `powermeter()`, её сглаживание, аппаратные входы и шкалы не переписывать.

До отдельного согласования этот документ не является разрешением на дополнительные изменения измерительной схемы или фильтрации.
